# Изменения Xray-core в CanaraLink для Windows

CanaraLink для Windows собран с [Xray-core](https://github.com/XTLS/Xray-core) v1.260327.0
(лицензия MPL-2.0). Изменены файлы пакета `proxy/tun`:

- `tun_windows.go` — заменяет оригинальный `proxy/tun/tun_windows.go`: закрытие TUN безопасно
  при работающем цикле чтения (ожидание прерывается событием закрытия), пакеты из кольца wintun
  копируются и сразу возвращаются;
- `handler_close.go` — новый файл: `Handler.Close()` закрывает стек gVisor и адаптер wintun.

В оригинале адаптер живёт до завершения процесса; в службе, которая подключается многократно,
адаптеры копились бы, а закрытие сессии во время ожидания пакетов роняло бы процесс.
